# Accessibility

- Use semantic navigation, headings, buttons, forms, tables, and status regions.
- Keep visible keyboard focus and a logical tab order.
- Give icon-only actions accessible names.
- Label inputs above the field; do not use placeholder text as the only label.
- Maintain WCAG AA contrast for normal text and controls.
- Status must include a word or meaningful icon, not color alone.
- Charts need a text summary or accessible data representation.
- Progress indicators expose current value and task name.
- Dialogs and drawers manage focus, dismiss with Escape where appropriate, and return focus to the opener.
- Respect reduced-motion settings.
- Ensure touch targets are at least 44px on mobile.
- Test long Chinese and English labels, 200% text zoom, and keyboard-only workflows.
