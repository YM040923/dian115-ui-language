# Anti-patterns

- Rebuilding the reference page pixel-for-pixel or copying its business names, route tree, demo data, logos, or artwork.
- Treating “lots of cards” as the same thing as information hierarchy.
- Making every page an overview dashboard.
- Showing metrics without source, time range, or state.
- Showing stale values as live facts.
- Using green/red/amber without status text.
- Using decorative English labels above every section.
- Animating every chart, card, or badge continuously.
- Hiding primary actions behind hover on touch devices.
- Using a floating assistant that covers content or navigation.
- Turning forms into dense unlabelled grids.
- Showing technical errors without a user-facing explanation or recovery path.
- Treating a click in a demo as proof of a backend operation.
- Inventing precise operational values without marking them as sample data.
- Combining multiple reference palettes, shadows, and radii without a named hierarchy.
